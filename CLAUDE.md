# Notes for Claude

This repo is a student team's workspace for the Otis Made to Move Communities (MTMC) 2026–2027 challenge, Year 7 theme: an AI-powered mobility solution for aging populations. Official briefs are in `docs/challenge/` (the English theme overview is authoritative; the Chinese one is a translation).

- Team members have little or no programming background. Explain any code, git operation or technical step in plain language, in Chinese unless asked otherwise.
- Keep the judging criteria in mind: creativity/originality, research quality, relevance to inclusive mobility, and real application of STEM and AI. AI must be a core part of the solution.
- Folder layout: `research/` (sources, data, interviews), `ideas/` (concepts), `presentation/` (final deliverables).
- Cite sources for any statistic added to research notes.
- Several teammates work in parallel: work on a branch and open a pull request rather than pushing directly to `main`, unless told otherwise.
